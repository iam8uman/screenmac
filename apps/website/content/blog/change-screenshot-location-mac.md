To change where screenshots are saved on a Mac, press **Shift-Command-5**, click **Options**, and pick a new location under **Save to**: Desktop, Documents, Clipboard, an app such as Mail, Messages or Preview, or **Other Location** for any folder. The choice applies to every screenshot and screen recording from then on, including ones taken with Shift-Command-3 and Shift-Command-4.

## How do I save screenshots to a different folder?

1. Create the folder first if it does not exist, for example **Screenshots** inside Pictures or Documents.
2. Press <kbd>Shift</kbd>-<kbd>Command</kbd>-<kbd>5</kbd> to open the Screenshot toolbar.
3. Click **Options**.
4. Under **Save to**, choose **Other Location**.
5. Find and select your folder, then click **Choose**.
6. Press **Esc** to close the toolbar.

Take a test screenshot with <kbd>Shift</kbd>-<kbd>Command</kbd>-<kbd>4</kbd> and check that it lands in the new folder. The folder also appears in the **Save to** list from now on, so switching back and forth later takes two clicks.

## What are the Save to options?

| Option | What happens |
| --- | --- |
| Desktop | The default. A PNG file on the desktop |
| Documents | A file in your Documents folder |
| Clipboard | No file. Paste with Command-V |
| Mail | A new email opens with the screenshot attached |
| Messages | The screenshot is added to a new message |
| Preview | The screenshot opens in Preview, unsaved |
| Other Location | Any folder you choose |

The app options are handy when every screenshot has the same destination, but most people are best served by a folder plus the clipboard shortcut for one-off pastes.

## Can I copy one screenshot without changing the setting?

Yes. Add <kbd>Control</kbd> to the shortcut and that capture goes to the clipboard while the Save to setting stays as it is:

- <kbd>Control</kbd>-<kbd>Shift</kbd>-<kbd>Command</kbd>-<kbd>3</kbd> copies the whole screen.
- <kbd>Control</kbd>-<kbd>Shift</kbd>-<kbd>Command</kbd>-<kbd>4</kbd> copies a selected area.

You can also drag the floating thumbnail that appears after a capture into any folder or app to put that one file there. The [shortcut finder](/tools/mac-screenshot-shortcuts) lists every combination if you forget.

## Why do my screenshots still go to the desktop?

- **You changed the setting while a capture was running.** Close the toolbar with Esc and take a new screenshot.
- **The folder was moved, renamed or deleted.** macOS cannot save to a folder that no longer exists. Pick it again with Other Location.
- **The folder is on an external drive that is not connected.** Choose a folder on your Mac, or connect the drive.
- **You are looking at another app's captures.** Apps such as Screenmac or CleanShot X have their own save settings, separate from the built-in tool.

If screenshots are not saved anywhere at all, work through [Mac screenshot not working](/blog/mac-screenshot-not-working).

## Is there a Terminal command for this?

You will find Terminal commands for the save location on many websites. Apple's own guides document the Options menu method above, which does the same job and is easy to undo, so there is no need for Terminal on current macOS versions.

## How should I organize screenshots once they are in a folder?

A dedicated folder makes cleanup easy:

1. In Finder, open the folder and choose **View → as List**.
2. Sort by **Date Added** so the newest captures are on top.
3. Every so often, select the old ones and move them to the Trash, or into a dated archive folder.

If you use a capture app instead of the built-in tool, check its history feature.
