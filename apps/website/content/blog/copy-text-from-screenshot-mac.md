To copy text from a screenshot on a Mac, open the screenshot in **Preview**, drag across the words to select them, then **Control-click** and choose **Copy Text**. This uses Live Text, which is built into macOS and recognizes printed text in images. Paste the text anywhere with <kbd>Command</kbd>-<kbd>V</kbd>.

It also works in Photos and Safari, and there are capture apps that grab text straight from the screen in one step.

## How do I copy text from a screenshot in Preview?

1. Double-click the screenshot to open it in Preview. If it opens in another app, Control-click the file and choose **Open With → Preview**.
2. Move the pointer over the text. It should change to a text cursor (an I-beam).
3. Drag across the words you want. Selected text is highlighted, like text in a document.
4. Control-click the selection and choose **Copy Text**.
5. Paste it where you need it.

If the pointer does not change over the text, choose **Tools → Text Selection** in Preview's menu bar and try again.

## How do I copy text from a screenshot right after taking it?

The thumbnail that appears in the corner after a capture opens a Markup window, which is built for drawing rather than selecting text. The quickest route is:

1. Take the screenshot as usual, for example <kbd>Shift</kbd>-<kbd>Command</kbd>-<kbd>4</kbd> and drag over the text.
2. Let the thumbnail disappear so the file saves.
3. Open the file in Preview and follow the steps above.

If you only need the text and not the image, capture to the clipboard is not enough: Live Text needs an image open in an app that supports it. Saving the file is the simple path.

## Can I copy text from images in Photos and Safari?

Yes. Apple documents Live Text in both:

- **Photos:** open a photo or screenshot that shows text, move the pointer over the text, select it, then Control-click and choose **Copy Text**, or press <kbd>Command</kbd>-<kbd>C</kbd>. Photos also lets you search the web for the selected text, share it, or call a phone number it finds.
- **Safari:** select text in an image on a web page the same way you would select ordinary text, then copy it.

This is handy for screenshots people send you. Drag the image from Messages or Mail into Preview, or save it to Photos, and copy from there.

## Why won't Live Text select anything?

| Problem | What to try |
| --- | --- |
| No text cursor appears | In Preview, choose Tools → Text Selection |
| Some words are missed | Zoom in before you capture so text is larger, then capture again |
| Text in an unsupported language | Apple notes Live Text is not available in all regions or languages |
| Handwriting or stylized fonts | Recognition is less reliable; type it out or retake at a larger size |
| Text inside a video | Pause the video and take a screenshot, then open it in Preview |

The most effective fix is usually a sharper capture. Text recognition works best on large, high-contrast text, so zoom the source in (<kbd>Command</kbd>-<kbd>+</kbd> in most apps) before you take the screenshot.

## Which apps copy text from the screen in one step?

If you grab text from images often, a capture app with OCR saves the trip through Preview. Two that say so on their own sites:

| App | How it works | Price |
| --- | --- | --- |
| Shottr | Press a hotkey, select an area, and the text is copied | Name your price, $0 allowed |
| CleanShot X | Copies text from any image, video or scan; 30+ languages; on-device | $35 one-time with a year of updates |
| Built-in Live Text | Open the image in Preview or Photos, select, Copy Text | Free, included in macOS |

Screenmac does not recognize text yet: it is on the planned list, not in the app. What it does do is capture and redact, so if the reason you are copying text is to share it without the private parts, you can blur or block those parts and send the image instead. Try that in the free [browser screenshot editor](/editor).

## Should I paste text or share the screenshot?

Paste the text when people need to search it, edit it or read it on a small screen. Share the image when layout matters, such as an error dialog or a design. When the screenshot contains personal details, copy only the text you need or [redact the image before sharing](/blog/redact-sensitive-info-screenshot).
