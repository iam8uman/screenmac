# Screenmac Roadmap

A phase is complete only when its exit criteria were **actually verified**. Each item lists how it was verified. `docs/CHECKLIST.md` holds the task-level checklist.

Status key: ✅ done and verified · 🟡 implemented, verification pending · ⬜ not started

## Baseline audit (2026-10-23)

The inherited draft claimed Phases 1–2 complete. Audit findings:

- Website: landing sections existed but the demo editor supported only a few tools, had no selection/resize, and its visual design did not meet the PRD's "premium" bar. It has been rebuilt.
- Native: a menu bar skeleton with full-screen capture only; area, window, editor, Quick Access, hotkeys and recording threw "not implemented". The roadmap's "xcodebuild succeeds" claim had no recorded evidence. The app was rewritten as Screenmac.
- Product renamed from FrameFlow to Screenmac on 2026-10-23.
