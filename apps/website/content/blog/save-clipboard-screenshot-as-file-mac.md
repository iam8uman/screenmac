To save a copied screenshot as a file on a Mac, open **Preview**, choose **File → New from Clipboard**, then choose **File → Save** or **File → Export** and pick a name, format and folder. Preview turns whatever image is on the clipboard into a new, unsaved document. It is the fastest built-in way to rescue a screenshot you copied with Control instead of saving.

## How do I turn a copied screenshot into a file with Preview?

1. Make sure the screenshot is still on the clipboard (you have not copied anything since).
2. Open **Preview** from Applications, or with Spotlight (<kbd>Command</kbd>-<kbd>Space</kbd>, type Preview).
3. Choose **File → New from Clipboard**. A new window opens with your screenshot.
4. Choose **File → Export**.
5. Pick a **Format**: PNG for screenshots of text and interfaces, JPEG for a smaller file.
6. Name the file, choose a folder and click **Save**.

If Preview opens its file browser at launch, click **Cancel** first; the File menu is then available.

## Why is New from Clipboard unavailable?

The menu item only works when the clipboard holds an image.

| What happened | Fix |
| --- | --- |
| You copied text or a link after the screenshot | Retake the screenshot, then go straight to Preview |
| You restarted or logged out | The clipboard was cleared. Retake it |
| The screenshot was taken without Control | It saved a file instead. Check the desktop or your [save folder](/blog/where-do-screenshots-go-mac) |
| The shortcut did not fire at all | See [Mac screenshot not working](/blog/mac-screenshot-not-working) |

The clipboard holds one item at a time, which is the most common reason a copied screenshot disappears.

## What other apps can save a clipboard image?

Any app that accepts a pasted image and can export it will do. Two that run in your browser and need no install:

- **The browser editor:** open the free [screenshot editor](/editor), press <kbd>Command</kbd>-<kbd>V</kbd>, and click **Export PNG**. You can blur or annotate it first. The image stays in your browser.
- **The format converter:** paste into the [screenshot format converter](/tools/image-format-converter) to download a PNG, JPG or WebP directly.

Preview is quickest when you only want the file, and the editor is quickest when you also need to hide something.

## Which format should I save as?

| Format | Use it for |
| --- | --- |
| PNG | Text, code, interfaces. Sharp edges, larger files |
| JPEG | Photos, or when file size matters more than crisp text |
| HEIC | Smaller files for photos; not every app or website opens it |
| PDF | When the image goes into a document workflow |

Preview's Export menu shows HEIC, JPEG, JPEG-2000, OpenEXR, PDF, PNG and TIFF, and more if you hold Option while opening the Format menu.

## How do I avoid losing copied screenshots?

- **Save by default, copy on purpose.** Keep Save to set to a folder and add <kbd>Control</kbd> only when you will paste straight away. See [how to copy a screenshot to the clipboard](/blog/copy-screenshot-to-clipboard-mac).
- **Drag the thumbnail.** Take a normal screenshot and drag the floating thumbnail into your chat or document. You get the paste and a saved file.
- **Use a capture history.** Capture apps that keep a history let you find earlier captures after the clipboard has moved on. [Screenmac](/download) keeps a local capture history on your Mac and lets you copy, save or drag each capture from its Quick Access preview.
